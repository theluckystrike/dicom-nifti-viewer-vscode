# Tags and the anonymity check

The tag table lists every element of the slice you are on: tag, VR, name and value, with sequences indented. Type in the search box to filter by tag number, name or value. Double-click a row to copy it.

A yellow bar appears when Patient's Name or Patient ID is filled, and it lists other identifying tags it finds, such as the birth date. Those rows are marked in the table too. Clear them with your de-identification tool before you share data or commit it to a repository.
