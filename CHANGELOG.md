# Changelog

## 0.1.3 (2026-11-07)

- The Marketplace name is now "DICOM Viewer, MRI Viewer & CT Viewer (NIfTI)" (it was "DICOM Viewer & NIfTI Viewer for CT and MRI"). The extension id, commands and settings stay the same.

## 0.1.2 (2026-11-07)

- The Marketplace description now starts with "DICOM viewer, NIfTI viewer and MRI viewer for VS Code".
- Marketplace search keywords updated, with the phrases people search for first.

## 0.1.1 (2026-11-07)

- "More free viewers" now starts with the Zovo extensions most related to this one. Picking one opens its Marketplace page, where you choose to install it.
- The README has a "Support Zovo" section with GitHub Sponsors and the developer's GitHub profile, and "More tools by Zovo" lists related extensions.

## 0.1.0 (2026-11-06)

- First release. Opens DICOM files, DICOMDIR and DICOM folders, `.nii` and `.nii.gz`.
- Implicit and explicit VR, big endian, deflated and RLE Lossless DICOM. Compressed JPEG, JPEG-LS, JPEG 2000 and HTJ2K files open with their tags and a message.
- CT brain, soft tissue, lung and bone presets, drag to set the window, axial, coronal and sagittal views, zoom and pan.
- Value and HU under the cursor, a searchable tag table and the anonymity check for Patient's Name and Patient ID.
- Export the current slice as PNG.
- Sponsor and More free viewers links under the image (setting `dicomViewer.showSupportLinks`).
- The "More free viewers" list and the README list now show the 15 Zovo extensions on the Marketplace under their current names, and 11 that are coming soon.
- Extensions for related files now come first, starting with HDF5 & NetCDF Explorer (H5 Viewer).
